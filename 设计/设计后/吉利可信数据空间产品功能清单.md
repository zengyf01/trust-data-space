## 一、产品概述

吉利可信数据空间是基于数标委《可信数据空间 能力建设要求》国家标准构建的数据要素流通平台，实现数据可用不可见、可信交换。

| 项目 | 说明 |
|------|------|
| **部署模式** | 单租户部署 |
| **并发能力** | 3000并发 |
| **高可用** | 99.9% |
| **部署方式** | Docker单机 / DockerCompose集群 / K8s生产部署 |
| **技术框架** | Spring Boot + MyBatis-Plus + Vue3 + Ant Design |
| **安全认证** | 国密SM2签名 + MaxKey SSO |

**技术栈版本详见第十二节**
