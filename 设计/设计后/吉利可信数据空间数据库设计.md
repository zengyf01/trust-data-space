# 吉利可信数据空间 数据库设计

> 版本：V1.0
> 日期：2026-06-12
> 状态：草稿

---

## 一、概述

### 1.1 数据库选型

| 类型 | 选型 | 说明 |
|------|------|------|
| 关系数据库 | MySQL 8.0 | 核心业务数据 |
| 缓存数据库 | Redis 7.x Cluster | 会话缓存、性能优化 |
| 对象存储 | MinIO | 文件存储 (图片、文档等) |
| 消息队列 | Kafka | 异步消息、日志同步 |

### 1.2 分库设计

| 库名 | 用途 | 数据量预估 |
|------|------|------------|
| tds | 服务平台数据 | 中等 |
| dos | 交付平台数据 | 大 |
| datar | 连接器数据 | 大 |
| public | 公共数据(字典、配置) | 小 |

### 1.3 命名规范

- 表名: 小写字母 + 下划线 (`tb_digital_contract`)
- 字段名: 小写字母 + 下划线 (`f_id`, `create_time`)
- 索引名: `idx_` + 表名 + 字段名
- 主键: `f_id` 或 `id`
- 时间字段: `create_time`, `update_time`, `delete_time`
- 租户: `f_tenant_id`
- 删除标志: `f_delete_mark` (0=未删, 1=已删)

## 八、Redis缓存设计

### 6.1 Key命名规范

```
{module}:{business}:{identifier}
```

### 6.2 缓存策略

| Key模式 | 用途 | TTL | 说明 |
|---------|------|-----|------|
| `tds:session:{userId}` | 用户会话 | 2小时 | 用户登录会话 |
| `tds:token:{appId}` | API Token | 5分钟 | API访问令牌 |
| `tds:user:{userId}` | 用户信息 | 30分钟 | 用户信息缓存 |
| `tds:member:{memberId}` | 机构信息 | 30分钟 | 机构信息缓存 |
| `tds:space:{spaceId}` | 数据空间 | 30分钟 | 数据空间缓存 |
| `dos:workorder:{code}` | 工单缓存 | 10分钟 | 工单信息缓存 |
| `dos:sandbox:{workOrderId}` | 沙盒缓存 | 10分钟 | 沙盒状态缓存 |
| `datar:connector:{sn}:heartbeat` | 心跳检测 | 3分钟 | 连接器心跳 |
| `datar:connector:{sn}:status` | 连接器状态 | 5分钟 | 连接器在线状态 |
| `datar:strategy:{productId}` | 产品策略 | 30分钟 | 产品策略缓存 |
| `datar:datasource:{id}` | 数据源配置 | 1小时 | 数据源配置缓存 |
| `public:dict:{type}` | 字典缓存 | 24小时 | 系统字典 |

### 6.3 缓存失效策略

- 会话信息：用户登出时主动删除
- 业务数据：数据变更时通过MQ同步删除
- 心跳数据：超时自动失效

### 7.1 高频查询索引

| 表名 | 查询场景 | 索引字段 |
|------|----------|----------|
| `tb_data_space` | 按机构查空间 | `org_id` |

| `evidence_log` | 按业务查存证 | `business_id + category` |
| `api_invoke_log` | 按时间查调用 | `invoke_time + app_id` |
