
**流程步骤：**

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 创建账号 | 用户在MaxKey注册账号 |
| 2 | 账号认证 | MaxKey SSO验证账号密码 |
| 3 | 创建机构 | 填写机构信息，上传资质文件 |
| 4 | 审核机构 | 平台管理员审核机构资质 |
| 5 | 注册连接器 | 创建连接器，分配唯一编号 |
| 6 | 下发凭证 | 生成AppId/AppKey用于API认证 |

**API接口：**
```
POST /api/maxkey/login                    # 登录
POST /api/tds/member/                    # 创建机构
POST /api/tds/tbConnector/              # 注册连接器
POST /api/open/tds/addMember            # 新增机构
```

### 16.1 核心流程状态总览

| 流程 | 状态流转 |
|------|----------|
| **机构入驻** | 待审核 → 已通过 / 已驳回 |
| **数据空间** | 创建 → 配置中 → 已完成 |
| **数据产品** | 编辑 → 待发布 → 已发布 / 已下架 |
| **数字合约** | 待签 → 签署中 → 执行中 → 已完成 / 已终止 |
| **交易订单** | 待审批 → 已审批 → 签署中 → 执行中 → 已完成 / 已取消 |
| **工单** | 待处理 → 处理中 → 已完成 / 失败 |
| **安全沙盒** | 创建 → 构建中 → 运行中 → 已停止 → 已销毁 |
| **隐私计算** | 创建 → 准备中 → 运行中 → 已完成 → 已归档 |
| **连接器** | 注册 → 部署中 → 在线 / 离线 |
| **策略管控** | 编辑 → 待生效 → 生效中 → 已失效 |
| **计量计费** | 用量记录 → 周期汇总 → 账单生成 → 已支付 / 已结算 |
